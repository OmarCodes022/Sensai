## Story 1

As a skincare creator, I want Sensai to show me exactly what it will change in work I already approved, so that nothing I signed off is rewritten behind my back

- The action, the file and the exact before and after are shown before anything changes, in the terminal and on the Campaign page
- Only `y` (or Apply) applies the change
- `n`, Enter, Ctrl+C (or Refuse) leave the file unchanged

## Story 2

As a creator, I want to be asked only when it matters, so that confirmations don't slow down normal work

- Edits to draft sections apply without a question
- Invalid edits are rejected before any question
- Running code with `run_python` asks with the same approval, and normal chat never asks
