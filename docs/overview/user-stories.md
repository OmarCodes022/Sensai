# User stories

Nadia runs the fictional skincare brand Serein Studio on her own. Every feature of Sensai has at
least two stories, written from her side.

## Streaming chat (B1)

- As a creator, I want to see the reply appear as it is written, so that I never stare at a blank screen.
- As a creator, I want to stop a reply at any moment, so that I don't wait for an answer I won't use.

## Personas (A5)

- As a creator, I want a writing persona for captions, so that my posts sound like my brand.
- As a creator, I want to switch to the community persona in the same chat, so that each task gets the right tone.

## Saved sessions and profile (M1)

- As a creator, I want to reopen yesterday's chat, so that I continue where I left off.
- As a creator, I want my preferences known in every chat, so that I don't repeat them.

## Branching and interrupt (X2)

- As a creator, I want to rewrite an earlier message and continue from there, so that I can try another direction without losing the first one.
- As a creator, I want to stop a reply going the wrong way, so that I can redirect it at once.

## MCP tools (T1)

- As a creator, I want Sensai to fetch my weekly figures from my metrics tool, so that my report uses real numbers.
- As a creator, I want to add tools by editing one config file, so that Sensai gains abilities without code changes.

## Tools: calculator and Python (T2)

- As a creator, I want my figures computed by code, so that my report never holds invented numbers.
- As a creator, I want to approve every Python run, and Sensai to fix its own failing code, so that nothing runs without my say and I never debug.

## Step-by-step reasoning (A1)

- As a creator, I want to see the plan, the tools used and the check, so that I can trust the answer.
- As a creator, I want Sensai to stop after a fixed number of steps and say what is still wrong, so that I never wait forever.

## Scheduled drafts (X5)

- As a creator, I want post ideas prepared on their own every week, so that they are waiting for me.
- As a creator, I want a failed run retried later, so that one problem doesn't stop the next drafts.

## Export and public links (X3)

- As a creator, I want my week's plan and chat saved as files, so that I can read or print them outside Sensai.
- As a creator, I want to share the calendar by a link only after I approve its exact content, so that nothing private goes public.

## Web search (T3)

- As a creator, I want Sensai to look up current trends, with sources, so that my ideas match what people talk about now.
- As a creator, I want to be told when search fails, so that I'm never misled.

## Questions and forms (X4)

- As a creator, I want Sensai to ask which product I mean, so that I don't get a caption for the wrong one.
- As a creator, I want to fix a typo or skip a question, so that one mistake doesn't derail the chat.

## Weekly campaign document (M4)

- As a creator, I want one weekly plan that grows piece by piece, so that my work isn't lost in the chat.
- As a creator, I want the plan still there after a restart, so that I can come back to it.

## Structured output (T5)

- As a creator, I want every edit in a fixed format, so that it can be saved without fixing it by hand.
- As a creator, I want each item checked against my brand data, so that a draft never points to a missing post or a bad claim.

## Human in the loop (A3)

- As a creator, I want to see the before and after when Sensai changes approved work, so that nothing I signed off changes behind my back.
- As a creator, I want to be asked only for approved sections, so that confirmations don't slow normal work.

## Team of agents (A2)

- As a creator, I want a reviewer to check every draft against my approved claims, so that no bad promise reaches me.
- As a creator, I want to see what each agent passed to the next, so that I understand the final post.

## Semantic cache (A6)

- As a creator, I want a common question answered at once, so that I don't wait for the same answer twice.
- As a creator, I want a cached answer only when my setup is the same, so that a fast answer is never a wrong one.

## Picked examples (A7)

- As a creator, I want Sensai to follow good examples of my content, so that drafts come in the right format.
- As a creator, I want to see which examples were used, so that I know whether they help.

## Usage log and statistics (EV3)

- As a creator, I want every exchange recorded, so that I can find what was asked and answered.
- As a creator, I want statistics on speed and errors, so that I notice when Sensai gets worse.

## Prompt versions (A4)

- As a creator, I want to compare two versions of the instructions side by side, so that I keep the better one with evidence.
- As a creator, I want to go back to an older version, so that a bad change is easy to undo.

## Weekly run (T45)

- As a creator, I want my posts, DM replies, report and calendar prepared in one click, so that Monday takes minutes.
- As a creator, I want private DMs left out and every text checked, so that nothing unsafe gets into my week.

## File access within permissions (T4)

- As a creator, I want one settings file to say where Sensai may read and save, so that my other files stay private.
- As a creator, I want anything not allowed refused, so that a mistake or a trick can't reach private files.

## Content and privacy guardrails (EV2)

- As a creator, I want customer details removed before the model sees them, so that I never leak anyone's data.
- As a creator, I want unapproved claims stopped, so that I never publish a promise my brand can't support.

## Brand facts memory (M3)

- As a creator, I want Sensai to remember the facts I mention, so that I don't repeat them every session.
- As a creator, I want to see and correct those facts, so that Sensai never uses an outdated price or date.

## Advanced document search (R2)

- As a creator, I want answers from the current sheet of the right product, so that Sensai doesn't mix products or use an old claim.
- As a creator, I want weak matches dropped and scores shown, so that I can trust the sources.

## Answer scoring (EV1)

- As a creator, I want answers checked against my documents, so that unsupported statements are flagged.
- As a creator, I want a score for each version of Sensai, so that I know if a change made it better.

## Brand document search (R1)

- As a creator, I want Sensai to answer from my product sheets and customer questions, with sources, so that it uses real facts.
- As a creator, I want Sensai to say when my documents don't cover a question, so that it never invents a claim.

## Long conversations (M2)

- As a creator, I want long chats to keep working, so that a long planning session doesn't break.
- As a creator, I want to see how much context is used, so that I trust what Sensai remembers.

## Web interface

- As a creator, I want every feature in one page on my computer, so that I can do my whole week there.
- As a creator, I want to approve what runs and know that nothing is sent, so that I stay in control.
